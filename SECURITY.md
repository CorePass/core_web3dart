# Security Policy

## Supported version

Security fixes are applied to the latest released version of Core Web3Dart.
Users should upgrade before reporting behavior that has already been corrected.

## Reporting a vulnerability

Report security issues privately to the repository maintainers through the
private security-reporting channel on the project host. Include:

- the affected version;
- a minimal reproduction without real private keys or seed phrases;
- the expected and observed behavior; and
- the security impact.

Do not publish exploitable details before maintainers have acknowledged the
report and coordinated a fix. Never attach production credentials, wallet
backups, seed phrases, or private keys.
